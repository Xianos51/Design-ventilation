Aide - Design Ventilation

📋 Introduction

Cette application permet de concevoir et calculer des réseaux de ventilation en 2D.

🎨 Outils de dessin

  • Sélection : Sélectionnez et déplacez les éléments existants.
  • Caisson : Ajoutez un caisson de ventilation (point de départ).
  • Bouche : Ajoutez une bouche de ventilation (point de sortie).
  • Conduit ⭕ : Dessinez un conduit rond entre deux éléments.
  • Conduit ⬜ : Dessinez un conduit rectangulaire entre deux éléments.

🔢 Calculs

1. Placez un caisson (point de départ)

2. Ajoutez des bouches et connectez-les avec des conduits

3. Définissez le débit pour chaque bouche dans le panneau de propriétés

4. Sélectionnez le sens de l'air (Soufflage ou Aspiration)

5. Cliquez sur "Calculer" pour dimensionner automatiquement le réseau

📄 Export PDF

Exportez votre réseau avec toutes les informations : schéma, débits, dimensions, pertes de charge.

📊 Normes utilisées

L'application utilise les normes NF EN 13779 (Europe) et ASHRAE (États-Unis) pour les calculs.
